# Klazik

Static artist site for Klazik, centered on the visual identity and story around "Classified Sick."

## What It Includes

- A single-file HTML site
- Embedded visual assets
- Sections for artist positioning, media, and project storytelling
- No build step or framework requirement

## Run Locally

Open `klazik_site.html` directly in a browser.

```bash
open klazik_site.html
```

## Repository Notes

This is a lightweight static-site snapshot. If the project becomes an active production site, the next cleanup step is to split embedded assets into `assets/`, add a deployment target, and keep this README updated with the live URL.
